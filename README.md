# Reward Dependency Intelligence System

An interactive customer analytics and reward optimization application built with Python, Streamlit, Pandas, NumPy, Plotly, and scikit-learn.

## Features

- Customer data exploration and visualization
- Customer segmentation analysis
- Interactive reward economics simulation
- Reward targeting and policy comparison
- Policy stability analysis
- Unit economics sensitivity analysis
- Simulation audit results and methodology documentation

## Run locally

Install dependencies and start the app:

```bash
pip install -r requirements.txt
streamlit run app.py
```

## Data and limitations

This project uses synthetic customer data for educational and portfolio purposes. Results depend on the simulation design and economic assumptions.

Oracle analyses use simulated ground-truth information for evaluation and comparison, not as deployable predictions for real customers.

Results should be validated against appropriate real-world data before using them to make business decisions.
